# Object Oriented Programming (CS-112(g))

## Summary
This course builds on the programming knowledge introduced in the first-semester ICC course. It focuses on the object-oriented approach (in C++), program design and specification, and includes a mini-application developed as a two-person project.

## Topics
- Foundations of object-oriented programming: class structure, encapsulation, methods, inheritance, polymorphism, multiple inheritance
- Standard tool libraries (standard library)
- Generic programming (templates)
- Practical application of theoretical concepts through exercises and a project

## Keywords
C++ language, object-oriented programming

## Prerequisites
- CS-119(d) Information, Calcul, Communication
- Procedural programming basics in C++

## Learning outcomes
By the end of the course, students should be able to:
- Model a moderately complex real-world situation in C++ from a French description
- Analyze a complex problem and decompose it into sub-problems
- Design algorithms solving moderately complex tasks
- Translate an algorithm into an equivalent C++ program using object-oriented concepts
- Independently implement a medium-sized application using the object-oriented layer of C++
- Analyze advanced C++ code to describe its behavior or correct it if erroneous
- Test whether a program's output matches the requested task

## Teaching methods
Ex cathedra sessions complementing an online course (MOOC), practical computer exercises

## Expected work
Class participation, exercise solving, two-person project, personal work at home

## Assessment
Continuous assessment:
- Intermediate graded series: 17%
- Written exam (2h): 33%
- Two-person project: 50%
